# 🌉 СТАНДАРТ ТЗ ДЛЯ КОДЕРА 2.0 (ПРОЕКТ «МИНИКУРС»)

**Откуда берутся данные:** Контент-Бюро «Атлант» формирует утвержденные ТЗ уроков и сохраняет их в эту папку (`baza/approved_lessons/`).
**Куда сохраняется результат:** Готовые интерактивные HTML-файлы сохраняются в `out/client/`.

---

## 📋 СТРУКТУРА КАЖДОГО ТЗ НА ИНТЕРАКТИВ С ИИ:
1. **Метаданные:** Номер урока, целевой файл (`out/client/XX_lessonX.html`), endpoint бэкенда (`/api/...`).
2. **Текст видео/суфлера:** Чистый авторский текст Анатолия Фёдорова.
3. **Механика интерактива с ИИ:** 
   - Пошаговые поля ввода / карточки выбора (Факт ➔ Эмоция ➔ Действие ➔ Выгода ➔ Итог).
   - Системный промпт для Polza AI (`gpt-4o-mini`).
   - Детерминированный оффлайн-фоллбэк (на случай сбоя сети).
4. **Спецификация UI/UX:** Базовый дизайн Glassmorphism (`#F3F6F5`), вызовы `safeHaptic`, Notibot SDK v2.26.
