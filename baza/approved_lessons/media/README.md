# 📁 ПАПКА МЕДИА-АССЕТОВ ДЛЯ УРОКОВ

Сюда Контент-Бюро «Атлант» выкладывает файлы видео, аудио и иллюстраций для новых ТЗ.

Структура папок:
```
baza/approved_lessons/media/{НН}/
```
Где `{НН}` — двузначный номер урока (например, `media/26/lesson6_intro.mp4`).

Кодер автоматически перенесет файлы в `out/server/files/` при сборке экрана.
