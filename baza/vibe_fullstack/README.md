# 🚀 Vibe Fullstack Starter Kit — Уровень 2

Это твой **стартовый проект 2-го уровня** для создания умных Vibe-приложений с искусственным интеллектом и базой данных!

---

## ⚡ Быстрый старт

### 1. Открой папку в Antigravity IDE
Добавь папку `vibe-fullstack-starter-kit` как workspace в Antigravity IDE.

### 2. Настрой ключ ИИ в `.env`
Открой файл `.env` и добавь твой API ключ ИИ-провайдера (OpenRouter / VSEGPT / OpenAI):
```bash
AI_API_KEY="sk-or-v1-ваш-ключ-здесь"
```

### 3. Напиши ИИ-агенту
```text
Сделай ИИ-генератор тренировок с сохранением результатов в базу данных
```

---

## 🛠️ Что внутри проекта

| Технология | Зачем |
|---|---|
| **Next.js (App Router)** | Полноценный фреймворк для сайта и API |
| **Prisma + SQLite** | База данных прямо в проекте (файл `prisma/dev.db`) |
| **OpenAI / OpenRouter SDK** | Безопасное подключение ИИ на бэкенде |
| **Notibot Bridge SDK** | Интеграция с экосистемой Notibot и TMA |
| **Tailwind CSS** | Красивый дизайн и стили |
| **Zod** | Автоматическая защита входящих данных |
| **Audit Diagnostics** | Скрипт проверки безопасности `npm run audit` |

---

## ☁️ Публикация на Amvera Cloud

1. Залей проект на GitHub.
2. В панели Amvera создай проект из репозитория.
3. Добавь переменную `AI_API_KEY` в настройках Amvera.
4. Готово! Amvera автоматически подтянет `amvera.yml` и развернет твой сервис.
