## 2. СТАНДАРТ ТЗ ДЛЯ КОДЕРА (6 ОБЯЗАТЕЛЬНЫХ РАЗДЕЛОВ)

Все ТЗ сохраняются в папку: `baza/approved_lessons/`  
Формат файла: `tz_{НН}_{тип}.md` (например, `tz_16_lesson1.md`, `tz_03_lesson1_PATCH.md`).

Каждый файл ТЗ содержит **6 обязательных разделов**:
1. **Метаданные (YAML-шапка):** `lesson_number`, `target_file`, `api_endpoint`, `notibot_article_id`, `scenario`, `type`, `next_screen`, `has_ai_interactive`.
2. **Текст видеоурока / суфлера:** Дословный текст Анатолия Фёдорова (переносится 1-в-1).
3. **Механика интерактива с ИИ:** Пошаговые поля, карточки выбора, шкалы, схема JSON-запроса.
4. **Системный промпт для Polza AI:** Готовый промпт для `gpt-4o-mini` и формат JSON-ответа.
5. **Оффлайн-фоллбэк:** Детерминированный экспертный ответ при сбое сети.
6. **UI-указания:** Специфические требования к дизайну или «Стандартный дизайн».

## 3. РЕЕСТР ЗАНЯТЫХ API ENDPOINTS

При создании новых ТЗ запрещено использовать существующие endpoints:

| Endpoint | Назначение |
|---|---|
| `/api/psyquest` | Психологический квест (сценарий 1) |
| `/api/lesson1-strategy` | Урок 1 — стратегия (сценарий 1) |
| `/api/lesson2-strategy` | Урок 2 — карта притяжения (сценарий 1) |
| `/api/lesson4-strategy` | Урок 4 — вернуть силу (сценарий 1) |
| `/api/lesson5-synthesis` | Урок 5 — итоговый синтез (сценарий 1) |
| `/api/portrait-assessment` | Портрет-квест |
| `/api/send-telegram-summary` | Отправка разбора в Telegram |

> Для Сценария 2 зафиксирован стандарт префиксов: `/api/s2-lesson1-strategy`, `/api/s2-lesson2-strategy` и т.д.

## 4. МЕДИА-АССЕТЫ

Файлы видео/аудио передаются через: `baza/approved_lessons/media/{НН}/`  
Кодер автоматически копирует их в `out/server/files/` и подключает через `resolveMediaUrl()`.

---

## 5. ПРОТОКОЛ СИНХРОНИЗАЦИИ И ОБРАТНОЙ СВЯЗИ

1. **Реестр статусов:** Отслеживание статусов сборки происходит через `baza/approved_lessons/STATUS.md`.
2. **Замечания от Кодера:** В случае неполного ТЗ или нестыковок создается `baza/approved_lessons/FEEDBACK_{НН}.md`. Кодер НЕ придумывает логику сам, а ждет доработки ТЗ.
3. **Точечные обновления:** Изменения существующих экранов передаются через `tz_{НН}_{тип}_PATCH.md` с запретом модифицировать общие модули (`api-config.js`, `telegram-user.js`, `leaves-bg.js`).
