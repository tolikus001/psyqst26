# 🧠 Самообучающийся Аудитор Кода и Качества (Self-Learning Auditor)

Специализация: **Автоматический контроль качества, предотвращение повторных ошибок и непрерывное обучение на основе опыта разработки проекта.**

Агент обязан запускать проверку через этот скил **ДО** и **ПОСЛЕ** любых изменений в кодовой базе.

---

## 🔄 1. Цикл Непрерывного Обучения (Self-Learning Loop)

При каждом действии или анализе кода агент следует 4 шагам:

1. **Inspect (Инспекция)**: Проверить целевой код по Реестру известных ошибок (Раздел 2).
2. **Execute (Исполнение)**: Написать чистый, отказоустойчивый код с соблюдением всех стандартов.
3. **Verify (Верификация)**: Запустить чек-лист перепроверки (Раздел 3).
4. **Learn & Persist (Обучение)**: Если возникла новая ошибка, зафиксировать её в *Журнале уроков* этого скила, чтобы никогда больше её не повторять.

---

## 📚 2. Реестр Усвоенных Уроков и Недопустимых Ошибок

### 🎨 [УРОК 1] Базовый дизайн проекта — НЕИЗМЕНЯЕМЫЙ СТАНДАРТ
- **Правило**: Базовый дизайн взят строго из файла `baza/исходник миникурса/Псиквест_5.6.html` (стили в `theme.css`).
- **Палитра**: Фон `#F3F6F5` (`.app-shell`), Текст `#243139`, Вторичный `#68767C`, Акцент `#7F9B8E`, Морской `#45656D`, Линии `rgba(14,31,46,.10)`.
- **Запрет**: Запрещено самовольно менять палитру на темную, неоновую или стороннюю без прямого запроса пользователя.

### 📐 [УРОК 2] Центрирование заголовков и подзаголовков
- **Правило**: ВСЕ заголовки (`h1`, `h2`, `h3`, `h4`, `.question-title`, `.hero h1`) и подзаголовки (`.lead`, `.subtle`, `.eyebrow`, `.section-subtitle`, `p.subtitle`) **обязаны центрироваться по центру** (`text-align: center !important`).
- **Запрет**: Никаких заголовков с выравниванием по левому краю.

### 📱 [УРОК 3] Notibot Sandbox & Iframe Высота
- **Правило**: Использовать `min-h-[100dvh]` на `body` и контейнере `.app-shell`, `h-[100dvh]` на скроллящихся областях.
- **Запрет**: Строго запрещено `body { position: fixed }` и `overflow: hidden` на body (ломает `ResizeObserver` высоты Notibot и вызывает бесконечный цикл ресайза).
- **Запрет**: Не использовать устаревшие `100vh` или `h-screen`.

### 🛡 [УРОК 4] Ранний перехватчик сообщений Notibot
- **Правило**: В `<head>` каждой страницы обязан присутствовать ранний перехватчик `window.notibotInitData`:
```html
<script>
  window.notibotInitData = null;
  window.addEventListener('message', function(event) {
    if (event.data && event.data.type === 'NOTIBOT_INIT' && event.data.data) {
      window.notibotInitData = event.data.data;
    }
  });
</script>
```

### 📳 [УРОК 5] Безопасный Haptic Feedback
- **Правило**: Любые клики и взаимодействия с кнопками/ответами должны вызывать функцию `safeHaptic(type)` с 3 уровнями защиты (Notibot $\rightarrow$ Telegram WebApp $\rightarrow$ `navigator.vibrate` $\rightarrow$ silent catch).
- **Запрет**: Запрещен прямой вызов `window.Telegram.WebApp.HapticFeedback` без проверки на `undefined`.

### 🎬 [УРОК 6] Видеохостинг Kinescope и Потоковый Стриминг
- **Правило**: Все обучающие видео курса хостятся на **Kinescope** (`https://kinescope.io/embed/[ID]` или Kinescope CDN) в адаптивных 16:9 контейнерах.
- **CSP**: В `<meta http-equiv="Content-Security-Policy">` обязательны:
  - `frame-src 'self' https://kinescope.io https://*.kinescope.io;`
  - `media-src 'self' https: data: blob: https://*.kinescopecdn.net;`
  - `script-src 'self' 'unsafe-inline' https://kinescope.io https://*.kinescope.io;`

### 🚫 [УРОК 9] Полный запрет заглушек (No Stubs / No Placeholders)
- **Правило**: В коде, разметке и скриптах категорически **запрещены временные заглушки, моки, фейковые данные (Lorem Ipsum, placeholder.png, dummy IDs)**.
- **Причина**: Заглушки легко забыть перед переносом в прод, они ломают боевые Notibot-транзакции и требуют долгой ручной зачистки.
- **Требование**:
  - Использовать реальные тексты из транскрибаций автора.
  - Использовать настоящие медиа-ссылки (`lesson0.mp4`, `meditation_audio.MP3`).
  - Реальные Notibot-обработчики (`window.notibot.openProduct`, `window.notibot.sendMessage`).
  - Реальные пользовательские имена из Telegram (`Telegram.WebApp.initDataUnsafe.user`) без захардкоженных тестовых имён.

### 📦 [УРОК 10] Защита от обрезания разметки (Full Body Integrity)
- **Ошибка**: При редактировании `<head>` или стилей в больших файлах тело страницы (`<body>`) может быть случайно усечено.
- **Правило**: Любая модификация файлов обязана сохранять полный объём разметки `<body>...</body>`. Аудитор проверяет наличие закрывающего `</body>` и интерактивных карточек.

### 🔗 [УРОК 11] Бесшовная маршрутизация экранов Notibot (`openScreen` вместо прямых ссылок)
- **Ошибка**: Прямые ссылки `<a href="02_landing_partner.html">` или `window.location.href = '04_lesson2.html'` внутри Telegram WebApp вызывают всплывающее окно *"Перейти по ссылке"* или открывают пустую страницу в песочнице Notibot.
- **Правило**: Все переходы между страницами курса внутри кнопок и ссылок выполняются строго через `openScreen('target.html')` и `href="javascript:void(0);" onclick="openScreen('target.html'); return false;"`.
- **Механизм**: `openScreen` сопоставляет имя файла с ID статьи Notibot и вызывает `window.notibot.openArticle(id)`, обеспечивая мгновенное переключение без подтверждений Telegram.

### 🎨 [УРОК 12] Гармонизация элементов шапки (Avatar & Strategy Badge)
- **Правило**: Аватар пользователя и бейдж курса/стратегии в шапке используют единую цветовую систему (морской оттенок `#45656D`, фон `rgba(69, 101, 109, 0.10)` и тонкий контур).

### ⏸️ [УРОК 15] Обязательная авто-пауза видео при переходе к практике и навигации
- **Правило**: При ЛЮБОМ переходе пользователя к интерактивной практике (`goToStep2()`, `goToInteractive()`, `goToPractice()`) или навигации между экранами (`openScreen()`, `safeNavigate()`, `goToStep1()`, `goToVideo()`) воспроизведение видео Kinescope (iframe) и аудио ДОЛЖНО быть немедленно поставлено на паузу через вызов `pauseVideo()`.
- **Запрет**: Категорически запрещено оставлять играющее фоном видео или аудио при открытии практических шагов или следующего экрана.
- **Реализация**:
```javascript
function pauseVideo() {
  const iframes = document.querySelectorAll('iframe');
  iframes.forEach(iframe => {
    if (iframe && iframe.contentWindow) {
      try {
        iframe.contentWindow.postMessage(JSON.stringify({ event: 'pause', command: 'pause' }), '*');
        iframe.contentWindow.postMessage({ type: 'pause', command: 'pause' }, '*');
        iframe.contentWindow.postMessage({ event: 'command', command: 'pause' }, '*');
        iframe.contentWindow.postMessage('{"method":"pause"}', '*');
      } catch(e) {}
    }
  });
  const audios = document.querySelectorAll('audio');
  audios.forEach(a => { try { a.pause(); } catch(e){} });
}
```

## 🔍 3. Чек-Лист Перепроверки Кода (Audit Protocol)

Перед сохранением любого файла агент проверяет:

- [ ] **1. Дизайн**: Соответствует ли разметка палитре и токенам `theme.css`?
- [ ] **2. Центрирование**: Все ли заголовки и подзаголовки имеют `text-align: center`?
- [ ] **3. Без заглушек**: Проверено ли отсутствие `TODO`, `dummy`, `Lorem ipsum`, `placeholder.png`, тестовых моков?
- [ ] **4. Персонализация**: Работает ли извлечение имени и аватара из Telegram / Notibot?
- [ ] **5. Маршрутизация**: Используется ли `openScreen('...')` вместо прямых `href="..."` и `window.location.href`?
- [ ] **6. Авто-пауза видео**: Вызывается ли `pauseVideo()` при переходе к практике и переключении экранов?
- [ ] **7. Haptic**: Обернуты ли клики в `safeHaptic`?
- [ ] **8. CSP**: Разрешены ли домены `kinescope.io`, `*.notibot.ru`, `telegram.org`, `fonts.googleapis.com`?
- [ ] **9. Мобильная адаптивность**: Тестируется ли экран на ширину 320px–448px?
- [ ] **10. Синтаксис & Целостность**: Проверен ли код через `node scripts/repair-all.js` и наличие всех секций `<body>`?
- [ ] **11. Локация**: Сохранен ли файл строго в директории `out/client/`?
- [ ] **12. Отчёт пользователю**: Указан ли полный список изменённых файлов с ссылками?
